# Open RSS Reader

Open RSS Reader is a free RSS reader for Windows.
This project has been built with the support of AI.

## Features
- Feeds can be saved in folders;
- Light, Dark and System theme;
- Possibility to change font and size;
- Read later functionality;
- Possibility to download and store articles within the application;
- Backup & Restore feature for feeds, folders and settings (no articles);
- Read/Unread functionality;
- Open original article functionality;
- Feedly Enterprise account integrated via API Key;
- Some UI customizations;
- Search by title functionality;
